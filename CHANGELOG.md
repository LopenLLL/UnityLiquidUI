# Changelog

All notable changes to this package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-10-30
### Added
- Initial release of LiquidUI package.
- URP 17+ Native RenderGraph based `LiquidUIRenderFeature`.
- Multi-iteration downsampling and upsampling pyramid blur support via `BlurMidPyramid`.
- UPM package architecture and assembly definition `LiquidUI.Runtime`.
